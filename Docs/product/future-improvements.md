# Future Improvements

## Visual & UX

- Dynamic theme editor (user-chosen colour palettes or accessibility presets)
- Animated onboarding flow with motion-driven storytelling
- Enhanced event discovery with tags, filters, and location cues
- Realtime UI feedback for invitations and group chat reactions

## Design System

- Figma → Tailwind design token sync
- Create `useAccessibility` and `useErrorReporting` hooks at UI system level
- Shared component library (`@pairup/ui`) for web and internal tools

## Cross-Platform

- Mobile-native design tokens
- Adaptive layouts for foldable and tablet devices
- Unified iconography and colour behaviour between web and native builds

## Accessibility

- Automated accessibility audits (axe-core in CI)
- Live-region announcements for navigation and content changes
- Keyboard shortcuts for power users and screen-reader optimisations
- `prefers-reduced-motion` support
- High-contrast mode toggle
- Skip links
